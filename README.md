# DESIGN, IMPLEMENTATION, AND COMPARATIVE ANALYSIS OF FUSION STRATEGIES INVOLVING EEG, EMG AND IMU IN SILENT SPEECH DECODING.
Silent speech recognition aims to recognize spoken language without producing an audible speech signal. This technology has potential applications in Brain-Computer Interfaces, assistive communication and communication in situations where conventional speech is not suitable. However, reliable recognition across different users remains challenging because physiological signals vary substantially between participants.

This thesis investigates multimodal silent speech recognition using electroencephalography (EEG), surface electromyography (EMG) and inertial measurement units (IMU). A dataset was collected from 20 participants performing ten silently articulated words, with all modalities recorded synchronously. A complete processing pipeline was developed, including signal preprocessing, feature extraction, classical Machine Learning and Deep Learning classification. Classical models based on XGBoost, Support Vector Machines and Random Forest were compared to a multimodal Deep Learning architecture using separate modality encoders and learned gated fusion.

The experiments were evaluated using leave-one-subject-out (LOSO) cross-validation to investigate generalization to unseen participants. The results show that IMU is the most informative individual modality, while EMG provides additional discriminative information. EEG alone performs considerably worse in the current experimental setup. The best classical Machine Learning configuration achieved an accuracy of 0.533 ± 0.113, whereas the multimodal Deep Learning model achieved 0.699. To address inter-subject variability, Euclidean Alignment, CORAL and Domain-Adversarial Neural Networks (DANN) were investigated. DANN produced the best result, reaching a LOSO accuracy of 0.760 ± 0.122.

Overall, the results demonstrate that multimodal biosignals can be used to recognize silent speech and that learned multimodal representations and domain adaptation can significantly improve cross-subject performance. At the same time, further work is required to obtain a robust system suitable for real-world use.
